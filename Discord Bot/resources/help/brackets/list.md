# Bracket Commands
Tournament bracket, match, SVG, stream, forfeit, and no-show commands.
## /tournament bracket generate
Generate a single or double elimination bracket.
## /tournament bracket current
Show playable matches.
## /tournament bracket round
Show matches in a specific round.
## /tournament bracket match
Show one match as an embed.
## /tournament bracket report
Report a match score.
## /tournament bracket correct_report
Admin-only correction for completed match results.
## /tournament bracket forfeit
Staff records a player forfeit or DQ.
## /tournament bracket resolve_no_shows
Resolve due match no-shows and pending auto-DQs.
## /tournament bracket threads
Create Discord match threads.
## /tournament bracket stream_assign
Assign a match to stream.
## /tournament bracket stream_clear
Clear a streamed match assignment.
## /tournament bracket stream_list
Show streamed matches.
## /tournament bracket svg
Export the full bracket as SVG.
## /tournament bracket match_svg
Export one match as SVG.
