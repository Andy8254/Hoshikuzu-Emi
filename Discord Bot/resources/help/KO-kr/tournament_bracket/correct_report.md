# /tournament bracket correct_report
완료된 경기 결과 보고를 정정합니다.
## 사용법
`/tournament bracket correct_report id:<id> match_id:<match_id> score_a:<score> score_b:<score> confirm:CORRECT`
## 설명
저장된 경기 결과에서 잘못된 값이 발견됐을 때 사용할 수 있습니다.
이 복구 명령어는 최고 관리자만 사용할 수 있습니다.
## 참고
이 명령어를 사용할 때 확인 키워드 `CORRECT`가 필요합니다.
이 복구 명령어를 통해 영향을 받는 이후 라운드의 경기가 이미 완료됐는지도 확인해 주세요.
