# /tournament bracket generate
체크인된 플레이어로 대진표를 생성합니다.
## 사용법
`/tournament bracket generate id:<id> [type]`
## 설명
싱글 엘리미네이션, 더블 엘리미네이션, 라운드 로빈, Swiss 형식의 대진표를 생성합니다.
대진표 생성이 완료되면, 봇은 설정된 토너먼트 채널에 현재 진행 가능한 경기 스레드 생성을 자동으로 대기열에 넣습니다.
## 참고
참가 신청, 체크인, 그리고 시드 번호 배정이 끝난 뒤 대진표를 생성해 주세요.
`/tournament bracket threads`는 수동 복구가 필요하거나, 이후 특정 라운드의 스레드를 직접 생성해야 할 때 사용하세요.
