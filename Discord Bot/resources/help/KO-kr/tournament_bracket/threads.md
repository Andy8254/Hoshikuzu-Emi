# /tournament bracket threads
Discord 경기 스레드를 생성합니다.
## 사용법
`/tournament bracket threads id:<id> [round] [buttons]`
## 설명
현재 경기 또는 특정 라운드의 스레드를 생성합니다. 버튼이 있는 스레드는 Check in, Report Score, Forfeit, Call Staff 버튼을 표시합니다.
## 참고
대진표 생성 시 현재 진행 가능한 경기 스레드 생성 요청은 자동으로 대기열에 들어갑니다.
이 명령어는 수동 복구가 필요하거나, 이후 특정 라운드의 스레드를 직접 생성해야 할 때 사용하세요.
경기 스레드가 생성되면 해당 경기는 열린 상태로 표시되며, StAr 경기 미참가 유예 시간이 시작됩니다.
경기 미참가 유예 시간은 600초, 즉 10분으로 고정되어 있습니다.
