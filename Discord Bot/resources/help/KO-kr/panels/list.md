# 패널
참가 신청, 체크인, 경기 동작을 위한 플레이어용 버튼 흐름입니다.

## 사용 대상
플레이어는 버튼을 사용합니다. 스태프는 패널을 만들고 복구용 슬래시 명령어를 유지합니다.

## 흐름
패널은 입력을 줄여 줍니다. 스태프는 참가 신청/체크인 패널을 게시하고, 경기 스레드는 동작 버튼을 표시합니다.

## 명령어
- `registration`: 참가 신청 패널을 설명합니다.
- `checkin`: 체크인과 경기 동작 패널을 설명합니다.

## 도움말
명령어별 페이지는 `/bot help category:panels command:<command>`를 사용하세요.
