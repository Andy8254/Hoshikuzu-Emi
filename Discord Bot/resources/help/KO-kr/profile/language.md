# /profile language
사용자가 원하는 봇 UI 언어를 설정합니다.
## 사용법
`/profile language language:<EN-gb|KO-kr|none>`
## 설명
UI 언어를 서버 기본값으로 지정하시려면 `none`을 입력해 주세요.
## 참고
서버가 보조 언어 표시를 켠 경우 일반 응답 메시지는 기본 언어와 보조 언어가 함께 표시될 수 있습니다.
현재 지원되는 언어는 영어(영국 - `EN-gb`)와 한국어(KO-kr)입니다.
이외 다른 언어를 추가하거나, 번역에 오류가 있을 경우, 개발자에게 바로 문의해 주시기 바랍니다.
