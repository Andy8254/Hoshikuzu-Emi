# /profile link
지정한 플랫폼 계정을 사용자의 프로필에 연결합니다.
## 사용법
`/profile link platform:<platform> id:<username>`
## 설명
TETR.IO, Jstris, PPT2, TEC, Tetra eSports, Classic Tetris 또는 지원되는 다른 플랫폼의 유저네임을 사용자의 디스코드 프로필에 연결합니다.
## 참고
스태프가 알아볼 수 있는 공개 게임 내 유저네임 또는 ID를 입력하세요.
고의로 다른 사람의 유저네임을 입력한 것이 발각된 경우, 그 즉시 서버 차단 수준의 제재를 받게 됩니다. 이 점 주의해 주세요.
