# /profile
토너먼트 프로필, 연결된 플랫폼 계정, 언어 설정, TETR.IO 조회를 위한 개인 사용자 프로필 도구를 제공합니다.
## 사용 대상
주로 일반 사용자(또는 플레이어)가 사용합니다.
스태프는 참가 신청에 관한 지원을 제공하거나, 신원 확인 문제를 해결할 때 조회 페이지를 사용할 수 있습니다.
## 사용 방법
`/profile init`을 실행하고, `/profile link`로 계정을 연결한 뒤, 이벤트 중에는 토너먼트 패널을 사용하실 수 있습니다.
## 명령어
- `init`: 사용자의 로컬 토너먼트 프로필을 생성합니다.
- `link`: 사용자의 플랫폼 계정을 Discord 프로필에 연결합니다.
- `unlink`: 사용자와 연결된 플랫폼 계정 하나를 제거합니다.
- `show`: 사용자의 현재 플레이어 프로필을 표시합니다.
- `delete`: 사용자의 로컬 프로필 데이터를 삭제합니다.
- `language`: 사용자의 UI 표시 언어를 설정합니다.
- `tetrio`: 지정된 사용자의 TETR.IO 프로필을 조회합니다.
## 도움말
주어진 명령어에 대한 자세한 정보는 `/bot help category:profile command:<command>`를 통해 확인하실 수 있습니다.
