# /profile
토너먼트 신원, 연결된 플랫폼 계정, 언어 설정, TETR.IO 조회를 위한 개인 플레이어 프로필 도구입니다.

## 사용 대상
주로 플레이어가 사용합니다. 스태프는 참가 신청 도움이나 신원 확인 문제를 해결할 때 조회 페이지를 사용할 수 있습니다.

## 흐름
`/profile init`을 실행하고, `/profile link`로 계정을 연결한 뒤, 이벤트 중에는 토너먼트 패널을 사용합니다.

## 명령어
- `init`: 로컬 토너먼트 프로필을 생성합니다.
- `link`: 플랫폼 계정을 프로필에 연결합니다.
- `unlink`: 연결된 플랫폼 계정 하나를 제거합니다.
- `show`: 플레이어 프로필을 표시합니다.
- `delete`: 로컬 프로필 데이터를 삭제합니다.
- `language`: 개인 표시 언어를 설정합니다.
- `tetrio`: TETR.IO 프로필을 조회합니다.

## 도움말
명령어별 페이지는 `/bot help category:profile command:<command>`를 사용하세요.
