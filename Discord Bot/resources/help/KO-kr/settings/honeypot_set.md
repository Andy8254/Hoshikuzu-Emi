# /settings honeypot_set
자동 차단용 허니팟 채널을 활성화합니다.
## 사용법
`/settings honeypot_set channel:<channel>`
## 설명
예외 대상이 아닌 사용자가 지정된 채널에 메시지를 보내면, 봇은 해당 메시지를 삭제하고 사용자를 차단하며 `auto_ban` 서버 관리 기록을 남깁니다. 서버 관리 로그 채널이 설정되어 있다면 해당 기록도 로그 채널에 전송합니다.
## 예외 대상
봇, 서버 소유자, 봇 개발자, 설정된 최고 관리자 역할, 관리자 역할, 스태프 역할을 가진 사용자는 예외 처리됩니다.
## 참고
이 명령어는 일반 사용자가 사용할 일이 없는 채널에만 사용해 주세요.
설정 후 `/settings honeypot_show`로 활성화된 채널을 확인하는 것을 권장합니다.
