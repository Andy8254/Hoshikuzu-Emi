# Hoshikuzu Emi 도움말
기능은 아래 6개의 주요 영역으로 묶여 있습니다.
## 주요 명령어
- `/bot`: 도움말, 상태 확인, 봇 정보
- `/profile`: 프로필, 계정 연결, 언어 설정
- `/settings`: 서버 역할, 언어, 로그 설정
- `/mod`: 경고, 메모, 제재 기록
- `/misc`: 선택형 및 커스터마이즈 모듈
- `/tournament`: 참가 신청, 체크인, 대진 운영
## 토너먼트 하위 명령어
- `/tournament bracket`: 경기, 결과, 순위표
- `/tournament config`: 채널, 역할, 규칙 설정
## 사용자 상호작용
일반 사용자는 가능한 한 버튼을 사용해 주세요.
슬래시 명령어는 스태프 개입 또는 복구용으로 남겨두었습니다.
## 언어
한국어 도움말이 없으면 영어(영국, `EN-gb`)가 표시됩니다.
## 예시
- `/bot help category:tournament`
- `/bot help category:profile command:link`
- `/bot help category:misc`
