# /mod
경고, 메모, 타임아웃, 추방, 차단, 차단 해제의 저장 기록을 갖는 수동 서버 관리 도구입니다.

## 사용 대상
서버 관리자와 최고 관리자입니다. 이 명령어들은 사용자 또는 스태프 기록에 영향을 주므로 사유가 명확해야 합니다.

## 흐름
조치를 격상하기 전에 `history`를 사용하고, 필요에 따라 경고/메모를 기록하거나 조치를 수행합니다.

## 명령어
- `warn`: 사용자에게 경고를 기록합니다.
- `note`: 내부 스태프 메모를 기록합니다.
- `history`: 사용자의 서버 관리 기록을 표시합니다.
- `timeout`: Discord 타임아웃을 적용합니다.
- `clear_timeout`: Discord 타임아웃을 해제합니다.
- `kick`: 사용자를 서버에서 추방합니다.
- `ban`: 사용자를 서버에서 차단합니다.
- `unban`: 사용자의 차단을 해제합니다.

## 도움말
명령어별 페이지는 `/bot help category:moderation command:<command>`를 사용하세요.
