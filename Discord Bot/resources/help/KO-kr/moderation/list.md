# /mod
기본적인 서버 관리 도구를 제공하는 명령어입니다.
## 사용 대상
위 명령어는 서버 관리자와 최고 관리자만 사용할 수 있습니다.
위 명령어의 사용 기록은 모두 서버 내 데이터베이스에 저장됩니다.
사용자 및 스태프 팀에게 중대한 영향을 끼칠 수 있으니, 반드시 관리 팀과의 협의 하에 사용하시기 바랍니다.
## 사용 방법
사용자에 대한 제재를 내리기 전 `history`를 통해 이전 제재 사항을 확인합니다.
이후 필요에 따라 경고/메모를 기록하거나 추방 등의 제재를 내릴 수 있습니다.
## 명령어
- `warn`: 지정된 사용자에게 경고를 내립니다. 경고 기록은 서버 내 데이터베이스에 기록됩니다.
- `note`: 내부 스태프 메모를 서버 내 데이터베이스에 기록합니다.
- `history`: 사용자의 서버 관리 기록을 표시합니다.
- `timeout`: 지정된 사용자에게 타임아웃을 적용합니다.
- `clear_timeout`: 지정된 사용자에게 주어진 타임아웃을 해제합니다.
- `kick`: 지정된 사용자를 서버에서 추방합니다.
- `ban`: 지정된 사용자를 서버에서 차단합니다.
- `unban`: 지정된 사용자의 차단을 해제합니다.
## 도움말
주어진 명령어에 대한 자세한 정보는 `/bot help category:moderation command:<command>`를 통해 확인하실 수 있습니다.
