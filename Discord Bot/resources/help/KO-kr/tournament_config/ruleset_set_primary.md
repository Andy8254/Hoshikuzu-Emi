# /tournament config ruleset_set_primary
토너먼트 기본 규칙을 설정합니다.
## 사용법
`/tournament config ruleset_set_primary id:<id> first_to:<score> [deuce] [win_by] [score_cap] [allow_draw]`
## 설명
기본 경기 승리 조건을 정의합니다.
## 참고
점수 제한이 없으면 `score_cap:0`을 사용하세요.
듀스를 지정할 경우, 점수 차 승리(Win-by) 또는 골든 포인트(Golden Point)로 승리 조건을 설정할 수 있습니다.
