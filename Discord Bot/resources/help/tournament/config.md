# /tournament config
Configures tournament module settings.
## Channels
`set_channel`, `clear_channel`, `log_channel_assign`, and `log_channel_clear`.
## Roles
`roles`, `set_staff_role`, `set_admin_role`, `clear_staff_role`, and `clear_admin_role`.
## Format
`set_format id:<tournament_id> format:<format>` changes a tournament's default format.
## Rulesets
`ruleset_show`, `ruleset_set_primary`, `ruleset_set_secondary`, and `ruleset_clear_secondary`.
## Permissions
Most config commands require tournament staff/admin or Discord administrator permission depending on risk.
