# Settings Commands
Server-level settings for roles, language placeholder, and moderation logs.
## /settings show
Show server settings.
## /settings set_admin_role
Set the server admin role.
## /settings set_moderator_role
Set the server moderator role.
## /settings set_staff_role
Set the server staff role.
## /settings language
Set the language placeholder.
## /settings modlog_set
Set moderation log channel.
## /settings modlog_clear
Clear moderation log channel.
