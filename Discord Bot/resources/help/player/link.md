# /link
Links a platform account to your local player profile.
## Usage
`/link platform:<platform> id:<username>`
## Platforms
Choices include TETR.IO, Jstris, PPT2, TE:C, Tetra eSports, TGM, Classic, and Other.
## Notes
Use `/register` first. TETR.IO links can be used by TETR.IO profile and seeding features.
