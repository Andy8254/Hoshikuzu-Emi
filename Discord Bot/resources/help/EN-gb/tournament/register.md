# /tournament register
Registers or unregisters a player by slash command.
## Usage
`/tournament register id:<id> [username] [abort] [user]`
## Details
Players should register for events through the button provided on the registration panel.
If something unexpected happens, staff can target another user through the slash command.
## Notes
Regular players should use the registration panel posted in the registration channel.
Use `abort:true` to cancel registration.
