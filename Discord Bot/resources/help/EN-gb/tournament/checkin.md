# /tournament checkin
Checks in or unchecks a player by slash command.
## Usage
`/tournament checkin id:<id> [username] [abort] [user]`
## Details
Players should confirm attendance through the provided check-in button.
If panel check-in fails, staff can target another user and process check-in manually.
## Notes
Players should use the Check in button on the check-in panel.
Staff can use `abort:true` to undo check-in for the selected user.
