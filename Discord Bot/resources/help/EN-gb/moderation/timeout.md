# /mod timeout
Applies a Discord timeout to the selected user.
## Usage
`/mod timeout user:<user> duration:<seconds> reason:<reason>`
## Details
Duration is in seconds and must stay within Discord limits.
The bot records the action and reason in the server database.
## Notes
This temporarily restricts the user's ability to speak in the server.
Because this affects the user directly, use it only with a clear reason and appropriate staff/admin coordination.
