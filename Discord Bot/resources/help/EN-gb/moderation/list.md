# /mod
Manual moderation tools with stored history for warnings, notes, timeouts, kicks, bans, and unbans.

## Who Uses This
Moderators and admins. These commands affect users or staff records, so reasons should be clear.

## Workflow
Use `history` before escalation, then record warnings/notes or take action as needed.

## Commands
- `warn`: Records a warning for a user.
- `note`: Records an internal staff note.
- `history`: Shows moderation history for a user.
- `timeout`: Applies a Discord timeout.
- `clear_timeout`: Removes a Discord timeout.
- `kick`: Kicks a user from the server.
- `ban`: Bans a user from the server.
- `unban`: Unbans a user.

## Help
Use `/bot help category:moderation command:<command>` for a command-specific page.
