# /mod
Manual server moderation tools with stored history.
## Who Uses This
Moderators and admins only.
All command usage is stored in the server database.
These commands can seriously affect users and staff records, so use them after appropriate staff/admin coordination.
## Workflow
Use `history` before escalation to check prior moderation records.
After that, record warnings/notes or take action as needed.
## Commands
- `warn`: Records a warning for the selected user in the server database.
- `note`: Records an internal staff note in the server database.
- `history`: Shows moderation history for a user.
- `timeout`: Applies a Discord timeout to the selected user.
- `clear_timeout`: Removes a timeout from the selected user.
- `kick`: Kicks the selected user from the server.
- `ban`: Bans the selected user from the server.
- `unban`: Unbans the selected user.
## Help
Use `/bot help category:moderation command:<command>` for a command-specific page.
