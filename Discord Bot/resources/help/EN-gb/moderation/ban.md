# /mod ban
Bans the selected user from the server.
## Usage
`/mod ban user:<user> reason:<reason>`
## Details
Use this for serious rule violations where the user should be blocked from rejoining.
The bot records the reason in the server database.
## Notes
The banned user cannot rejoin until the ban is removed.
Because this is a severe action, use it only after confirming the target and coordinating with the server staff/admin team.
