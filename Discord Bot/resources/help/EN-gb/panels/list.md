# Panels
Player-facing UI/UX information for registration, check-in, and match actions.
## Who Uses This
Players should normally use buttons.
If something goes wrong, staff can still use slash commands for recovery.
## Commands
- `registration`: Explains the registration panel.
- `checkin`: Explains the check-in and match action panels.
## Help
Use `/bot help category:panels command:<command>` for a command-specific page.
