# Panels
Player-facing button workflows for registration, check-in, and match actions.

## Who Uses This
Players use the buttons; staff creates the panels and keeps slash commands available for recovery.

## Workflow
Panels reduce typing. Staff posts registration/check-in panels; match threads expose action buttons.

## Commands
- `registration`: Explains the registration panel.
- `checkin`: Explains check-in and match action panels.

## Help
Use `/bot help category:panels command:<command>` for a command-specific page.
