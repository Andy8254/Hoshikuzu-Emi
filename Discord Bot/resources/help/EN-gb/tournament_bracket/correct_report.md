# /tournament bracket correct_report
Corrects a completed match report.
## Usage
`/tournament bracket correct_report id:<id> match_id:<match_id> score_a:<score> score_b:<score> confirm:CORRECT`
## Details
Use this when an incorrect value is found in a stored completed match result.
Only admins should use this recovery command.
## Notes
This command requires the exact confirmation keyword `CORRECT`.
Before using it, check whether later-round matches affected by the correction have already been completed.
