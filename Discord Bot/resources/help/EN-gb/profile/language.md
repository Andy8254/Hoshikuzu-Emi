# /profile language
Sets your preferred bot UI language.
## Usage
`/profile language language:<EN-gb|KO-kr|none>`
## Details
Use `none` if you want your UI language to follow the server default again.
## Notes
Plain replies may show primary plus secondary language when the server enables secondary display.
Currently supported languages are English (GB - `EN-gb`) and Korean (`KO-kr`).
If you want another language added, or if you find a translation issue, please contact the developer.
