# Flavour Text

Flavour files are optional personality layers. They are not official language files.

Use them only for harmless keys such as:

- `hello.*`
- `beta.notice`
- `error.soft`
- `profile.flavour`

Do not use flavour text for:

- Moderation rulings
- Tournament disqualifications
- Appeals
- Privacy/legal text
- Audit logs
- Ban or DQ notices

Official translations belong in `resources/lang`.
